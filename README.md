Tools
- Microsoft Power BI Desktop
- Power Query Editor
- DAX (Data Analysis Expressions)
- Data modeling and relationships
- Interactive visualizations and report pages
Typical Project Workflow
1. Import the dataset into Power BI.
2. Inspect and clean the data using Power Query.
3. Create relationships and a data model where required.
4. Create calculated columns and measures using DAX where required.
5. Build report pages with relevant charts, cards, tables, slicers, and
   filters.
6. Review the report and validate that visuals reflect the data
   correctly.
7. Save the Power BI report (.pbix) in its corresponding project
   folder.
How to View the Projects
1. Open the required project folder.
2. Locate its Power BI report file (.pbix).
3. Open the file using Microsoft Power BI Desktop.
4. Use the report-page tabs, slicers, and filters to explore the
   dashboard.
Notes

  documented in each project's folder.

  to reflect the actual report contents.
